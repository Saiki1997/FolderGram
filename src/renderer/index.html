Organization rules

Send albums to topics by where they come from. Rules are checked from the top; the first that matches is used. Names you correct in the preview still win.

Patterns: * and ? wildcards, or /regex/. Several patterns: separate with commas. Names: {top} {parent} {folder} {album} {path} {level1} {level2}… {year} {month} {date} {count} {ext}.

Dictionary

Preferred spellings. Whole words in album and topic names are replaced: with “Marin Kitagawa” for “Marin”, “Marin - Set 01” becomes “Marin Kitagawa - Set 01”.
